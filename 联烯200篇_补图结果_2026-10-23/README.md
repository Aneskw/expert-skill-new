# 200篇补图结果与缺失原因

原批次200篇：191篇原提取完成、2篇仅部分结构化记录、7篇无可用反应记录。结构统计覆盖193篇，不能称为200篇全部提取成功。

具体实验反应物/产物结构：2983 → 11792 / 12158 有图，新增8809，缺图366。

## 为什么以前缺图

原记录大量只有编号、名称或文字说明，未保存可绘制连接结构；展示层依赖SMILES，因此文字记录存在也会显示无图。此次通过Evolab逐页转写结构候选并用RDKit绘图；图片内嵌在每篇HTML中，非论文截图。

## 剩余缺图原因

| 类别（按提取报告初步归类） | 条目数 |
|---|---:|
| 聚合物、材料或配位实体不适合单一分子图 | 83 |
| 现有来源不足以唯一定位结构 | 67 |
| 命名或中间体证据需进一步核对（含规则过严） | 46 |
| 混合物或未鉴定产物 | 46 |
| 身份、编号或图文关联冲突 | 45 |
| 通式或类别未展开 | 41 |
| 缺少或未关联补充材料 | 17 |
| 同位素分布需标注图 | 12 |
| 结构转写尚未完成 | 9 |

类别按现有原因文本归并，尚非逐条独立原文复核；完整原因及原文位置见逐项清单。

已发现工具约束过严：明确、无歧义的正文系统名称可提供结构证据，不应要求每个简单分子同时具有编号图。本次据原文名称补回5个；仅名称不完整、类别名或来源冲突时仍不猜测。

结构转写尚未完成和记录身份关联错误属于提取/数据问题；不能归责为原论文没有结构。聚合物、通式、同位素分布需增加专用图表示。原文未鉴定的产物、无确定组分的混合物应保留文字。缺少SI需获取并明确关联后再提取。
